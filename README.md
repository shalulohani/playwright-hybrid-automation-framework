# playwright-hybrid-automation-framework

Hybrid UI + API Automation Framework using Playwright, REST, and GitHub Actions. Demonstrates modern automation practices with reusable components, CI/CD integration, and scalable architecture for real‑world testing scenarios.

## Overview
This project showcases a hybrid automation approach combining UI and API testing. It is designed to demonstrate modern QA engineering skills, clean architecture, and CI/CD readiness.

## Features
- Playwright‑based UI automation with Page Object Model  
- REST API automation with request/response validation  
- Config‑driven architecture for environment handling  
- Reusable utilities (logger, API client, test data manager)  
- GitHub Actions pipeline for automated test execution  
- Readable reports (HTML/Allure planned)

## Setup Instructions
1. Clone the repository  
   `git clone https://github.com/<your-username>/playwright-hybrid-automation-framework.git`
2. Install dependencies  
   `npm install`
3. Run tests  
   `npx playwright test`
4. View reports  
   `npx playwright show-report`
